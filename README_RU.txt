СОСЕД KZ — ПЕРВАЯ ТЕСТОВАЯ ВЕРСИЯ

Что работает:
- категории услуг;
- поиск по объявлениям;
- добавление объявлений;
- избранное;
- переход в WhatsApp;
- сохранение данных локально в браузере телефона.

ВАЖНО:
Это демонстрационная версия. Объявления хранятся только на том устройстве и в том браузере, где их добавили. Другие пользователи их пока не увидят. Не размещайте реальные персональные данные до подключения общей базы и политики конфиденциальности.

КАК ОТКРЫТЬ:
1. Распакуйте архив.
2. Откройте index.html в браузере для предварительного просмотра.
3. Для установки как PWA нужно сначала разместить все файлы на HTTPS-хостинге.
4. После публикации откройте сайт в Chrome на Samsung и выберите меню браузера → Добавить на главный экран / Установить приложение.

Для APK потребуется опубликованный HTTPS-сайт и отдельная упаковка. Сам по себе этот архив ещё не является APK.
